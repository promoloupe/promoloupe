# Code of Conduct

promoloupe follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

By participating in this project, in issues, pull requests, discussions or any
other project space, you agree to abide by its terms.

## Reporting

To report a violation, email **conduct@promoloupe.com**. Reports are read only
by the project maintainers and handled confidentially. If a maintainer is
involved in the incident, they will not take part in handling the report.
